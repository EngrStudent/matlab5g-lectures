# Fundamentals (P00a and P00b)

Companion code and notes for two lectures that share this folder:

- [P00a — Grid and Waveform](https://www.youtube.com/watch?v=wyDEW97bGpE)
- [P00b — Map of the Link](https://www.youtube.com/watch?v=P6A8iGZS2Q0)

## P00a — Grid and Waveform

- Narration script: [p00a_narration_v3.md](p00a_narration_v3.md)
- MATLAB demo: [p00a_bits_and_grid_demo.m](p00a_bits_and_grid_demo.m), [p00a_ofdm_and_cp_demo.m](p00a_ofdm_and_cp_demo.m)
- Build-it exercise: inside the MATLAB demo, in the "Build it" section. Work it yourself; answers are not in this repository.
- Lecture notes: none in this folder; follow the narration script and the demo.
- Checks: none in this folder.

## P00b — Map of the Link

- Narration script: [p00b_narration_v2.md](p00b_narration_v2.md)
- MATLAB demo: [p00b_signal_map_and_coding_demo.m](p00b_signal_map_and_coding_demo.m), [p00b_softbits_and_dynamics_demo.m](p00b_softbits_and_dynamics_demo.m)
- Build-it exercise: inside the MATLAB demo, in the "Build it" section. Work it yourself; answers are not in this repository.
- Lecture notes: none in this folder; follow the narration script and the demo.
- Checks: none in this folder.

## What you need

MATLAB R2024a or later and the 5G Toolbox. Some later tracks also need Communications Toolbox or Phased Array System Toolbox; the demo header lists them when they are required.
