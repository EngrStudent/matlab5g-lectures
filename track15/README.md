# T15 — End to End

[T15 — End to End](https://www.youtube.com/watch?v=8zydzAzfjBw).

## In this folder

- Narration script: [track15_narration_v3.md](track15_narration_v3.md)
- MATLAB demo: [track15_end_to_end_demo.m](track15_end_to_end_demo.m)
- Build-it exercise: inside the MATLAB demo, in the "Build it" section. Work it yourself; answers are not in this repository.
- Lecture notes: [track15_lecture_notes.md](track15_lecture_notes.md)
- Checks: [track15_checks.md](track15_checks.md)

## What you need

MATLAB R2024a or later and the 5G Toolbox. Some later tracks also need Communications Toolbox or Phased Array System Toolbox; the demo header lists them when they are required.
